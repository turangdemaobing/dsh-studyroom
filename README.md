# dsh-studyroom

海南大学海甸校区 · 每日自习室查询页。每晚自动抓取学校「自习室预告」公告，按「同教学楼优先 → 房间号相近 → 楼层」的规则，为每节课挑出最近的自习室。

- 页面：`index.html`（纯静态，无依赖，直接打开即可）
- 抓取/生成：`updater.py`（`python updater.py` 重建 index.html）
- 课表数据：`courses.json`（已脱敏，不含学号/姓名）
- 自动更新：`.github/workflows/daily.yml`，每天 UTC 15:00（北京 23:00）跑一次

规则说明：

- 当天没课的书段优先 4 号、5 号教学楼；
- 有课的时段只在**上课所在教学楼**内推荐，按房间号差 → 楼层差排序，不跨楼；
- 公告未发布时页面顶部会提示，不会编造房间。

数据来源：海南大学后勤保障部 · 服务指南 · 自习室预告
<https://he.hainanu.edu.cn/baozhang/info/1033/15003.htm>
